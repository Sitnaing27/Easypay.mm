🔥 Firebase Setup — တစ်ကြိမ်သာ လုပ်ရပါသည်
Real-time sync (သင် rate ပြင် → Customer app မှာ ချက်ချင်း update) အတွက် Google Firebase လိုပါသည်။ အခမဲ့ဖြစ်ပြီး ၅ မိနစ်သာ ကြာပါသည်။
1
console.firebase.google.com → Add project → name ထည့် (ဥပမာ easypay-mm) → Continue × 2
2
ဘယ်ဘက် menu → Build → Realtime Database → Create database → location ရွေး → Start in test mode → Enable
3
⚙️ Project Settings → General tab → scroll down → Your apps → </> (Web) icon → App nickname ထည့် → Register → firebaseConfig values များ copy
4
အောက်ပါ fields တွင် paste လုပ်ပြီး Save နှိပ်ပါ
